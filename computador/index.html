Análise do Computador

Programa gratuito para Windows que verifica as peças do computador, encontra os problemas e mostra o passo a passo para resolver cada um.

Baixar para Windows

Windows 10 ou 11 · arquivo .zip de 33 KB · não instala nada

Você está no celular. Este programa é para computadores com Windows. Para o celular, use a Análise de Celular.

O que ele verifica

  • Saúde e desgaste dos discos (HD e SSD)
  • Espaço livre e o que dá para limpar
  • Memória RAM e qual pente comprar
  • Processador sobrecarregado
  • Temperatura e bateria (notebooks)
  • Telas azuis e desligamentos inesperados
  • Peças sem driver ou com defeito
  • Driver de vídeo desatualizado
  • Erros de hardware registrados pelo Windows
  • Windows sem suporte e atualizações pendentes

No final aparece uma nota de 0 a 100 e um relatório com cada problema encontrado e como resolver.

Como usar

  1. Baixe o arquivo

    Clique em “Baixar para Windows”. O arquivo vai para a pasta Downloads.

  2. Desbloqueie o arquivo

    Clique com o botão direito no arquivo baixado e escolha Propriedades. Embaixo, em “Segurança”, marque Desbloquear e clique em OK. Sem isso, o Windows 11 pode bloquear o programa.

  3. Extraia a pasta

    Clique de novo com o botão direito no arquivo e escolha Extrair tudo e depois Extrair. Não rode o programa de dentro do .zip.

  4. Abra o programa

    Na pasta extraída, dê dois cliques em CLIQUE AQUI para analisar. Não abra os arquivos da subpasta arquivos: eles são o programa.

  5. Permita a análise

    Quando o Windows perguntar se permite fazer alterações, clique em Sim. Isso serve só para ler a temperatura e a saúde dos discos. Se clicar em Não, a análise roda mesmo assim, com menos informações.

  6. Veja o relatório

    Em alguns segundos o relatório abre numa janela. Uma cópia fica salva na pasta Relatorios, ao lado do programa.

Se aparecer “O Controle Inteligente de Aplicativos bloqueou…”

Essa proteção do Windows 11 não tem a opção de executar mesmo assim. Apague a pasta extraída, faça o passo 2 (Desbloquear nas Propriedades do arquivo .zip) e extraia de novo.

Se aparecer “O Windows protegeu o computador”

É normal em programas baixados da internet que não são vendidos em loja. Clique em Mais informações e depois em Executar assim mesmo.

O programa é aberto e transparente: ele só lê informações do computador, não instala nada, não muda configurações e não envia nenhum dado. Quem quiser pode abrir o arquivo arquivos\AnaliseHardware.ps1 no Bloco de Notas e ver tudo o que ele faz.
